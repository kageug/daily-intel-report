5月に入り、SNS業界は「オリジナルコンテンツ保護」と「プラットフォーム再編」の2大テーマが加速している。

Instagramの転載アカウント排除策、X Communities廃止のカウントダウン、Threads広告のグローバル展開、YouTubeのAI創作ツール拡充が同時進行し、各プラットフォームの勢力図が大きく動いている。

直近の流れ

4月22日にXがCommunities機能の5月6日廃止を発表（後に5月30日に延期）、同24日にXChatをiOS向けリリース。

Instagramは4月中に矢継ぎ早のアップデート（コメント編集、Your Algorithm拡張、EditsアプリのAI動画生成）を実施。

YouTubeは4月14日にライブ配信の収益化を大幅強化し、4月22日にSiriusXMとの音声広告パートナーシップを発表した。

今日の新しい動き（5月1日〜2日）

最大のニュースはInstagramが4月30日〜5月1日に発表した「コンテンツアグリゲーター排除」ポリシー。

他者のコンテンツを転載するだけのアカウントは、写真・カルーセル投稿においてもアプリ全体のレコメンデーション（フィード・Discover）から除外される。

これまでリール限定だった保護措置が全投稿形式に拡大された。

Instagram責任者Adam Mosseriは「最高のミームクリエイターは、第三者のコンテンツを"まぎれもなく自分のもの"にする」と述べ、単なるスピード変更・ウォーターマーク追加・スクリーンショット転載は「低品質な編集」として保護対象外と明言。

月単位でアカウント全体の投稿パターンを評価する仕組み。

フォロー済みアカウントの表示には影響しない。

X Communities廃止まで残り28日

5月6日の当初期限は5月30日に延期されたが、機能自体は既に新規作成不可。

XChatのグループチャットは現在350人上限で、500人→1,000人と段階的に拡大予定。

新たに公開参加リンク（joinable links）機能が追加され、タイムラインに共有するだけでフォロワーが即座にグループに参加可能に。

Community管理者はメンバーをXChatに移行できる。

製品責任者Nikita Bierは「利用率0.4%なのにスパム報告の80%を占め、チームの週の半分を消費していた」と廃止理由を説明。

Threads 4億MAU突破と広告グローバル展開

Threadsは月間アクティブユーザー4億人を突破し、1月にはデイリーアクティブでX（1.25億）を上回る1.415億に達した。

4月からMeta Ads Manager経由でグローバルに広告配信を開始。

「For You」フィード限定で画像・動画・カルーセル広告が表示される（「Following」フィードは対象外）。

フォロワー5,000人以上の認証済みクリエイター向けに収益シェアプログラムを導入し、2026年の全体報酬プールは1〜2億ドル規模と推定。

ただし、テキストベースの収益はReelsの1/10〜1/6程度にとどまる現実もある。

YouTubeのAI創作ツール大攻勢

YouTubeはGoogle DeepMindのVeo 3 FastをShorts作成フローに統合し、クリエイターが無料でAI動画背景や短尺クリップを生成可能に。Reimagine機能では、既存Shortsの1フレームから8秒の新クリップを生成。

さらにAIアバター生成も導入し、写真とスクリプトから多言語対応の仮想プレゼンター動画を作成可能。

4月15日にはShorts完全オプトアウト機能（視聴時間ゼロ設定）がグローバルに展開され、ユーザーはShortsタブ自体を非表示にできるようになった。

プラットフォーム側ではInstagramのカルーセル並べ替え・リールタップ一時停止、X(Twitter)のGrok翻訳切り替えによる日米ユーザー越境現象、TikTok Shopの日本5万セラー突破、YouTubeショッピングアフィリエイト日本開始（楽天市場提携）と、クリエイターエコノミー基盤の拡充が加速中。

櫻坂46 5thアニラ — 国立競技場2days完走（4/11-12）

MUFGスタジアム（国立競技場）で坂道グループ初・女性グループ初の新国立ライブを2日間完走。

動員数は2days合計14万人。

DAY2（4月12日）終演後にはサプライズ4連発：(1) 15thシングル「Lonesome rabbit / What's "KAZOKU"?」6月10日発売（坂道グループ初の両A面）、(2) 2026年7月〜全国6都市12公演のアリーナツアー、(3) 11月ZOZOマリンスタジアムでの6thアニバーサリーライブ、(4) 2027年に坂道グループ初のアジアツアー。

1stシングルセンター・森田ひかるが「今日この景色を見た時に初めて再生を選んでよかったなと思いました」と涙のコメント。

ハッシュタグ「#櫻坂5thアニラ_国立競技場_DAY2」がXトレンド入り。

終演後22時頃には「櫻坂チャンネル」緊急YouTube生配信も実施された。

関係者席には土田晃之、ハライチ・澤部佑、ネプチューン・堀内健のほか日向坂46メンバーも来場。

名探偵プリキュア！ — キュアアルカナ・シャドウ変身回（4/12放送）

第11話でキュアアルカナ・シャドウ（CV:東山奈央）が初変身。

変身バンクが「美しすぎる」「かっこかわいい」とSNSで大反響を呼び、「#precure」がXトレンド1位、「アルカナシャドウ」もトレンド入り。

4月11日からは全国1,000店舗以上で「キュアアルカナ・シャドウ大作戦」店内放送がスタート（5月10日まで）。

TBS日曜劇場『GIFT』初回放送（4/12）

堤真一主演、車いすラグビーを題材にした完全オリジナルドラマの第1話が25分拡大で放送。

山田裕貴・細田佳央太らの"ラグ車捌き"による試合シーンの臨場感が話題となり、「想像以上」「役者がすさまじい」とネット騒然。

Xでのリアルタイム関東視聴率は7.7%と報告されている。

共演に有村架純。

第2話のあらすじも即日公開。

獅白杯 -オフライン- 横浜BUNTAI（4/11-12）

ホロライブ・獅白ぼたん主催のスト6大会が初のオフライン開催。

DAY1（4/11）は3on3ダブルエリミネーション8チームトーナメント、DAY2（4/12）は獅白ぼたんvsラプラス・ダークネスの東西対抗戦。

レッドブル協賛、大暮維人の描き下ろしイラスト出展も話題に。

X(Twitter) — 日米越境現象が継続

3月末にGrok AI翻訳への切り替えとアルゴリズム変更により、米国ユーザーのフィードに日本語投稿が大量流入する「Japanese-American X Crossover」が発生。

佐世保の焼肉店で米兵がベーコンを焼く投稿がきっかけで日米文化交流が爆発的に拡大。

米国務省のサラ・ロジャース次官が「Americans want to know Japan better」と歓迎。

Japan Timesは「Japanese X is now America's favorite corner of the internet」と報道（4/1）。

4月中旬に入っても現象は継続中。
