AWSアカウントからAnthropicのネイティブClaude Platformに直接アクセスできる新サービス。

2. Claude Code v2.1.139リリース（5/11）。

目玉は「Agent View」（研究プレビュー）— 複数のClaude Codeセッションを1つのCLI画面で一覧管理できる機能。

各セッションの状態（実行中/入力待ち/完了/失敗）を一覧表示し、バックグラウンド実行・インライン返信・フルセッション切替が可能。

`/goal`コマンドも追加され、完了条件を設定するとClaude Codeがその条件を満たすまで自律的に作業を継続する。

3. 安全性研究「Teaching Claude Why」の報道が拡大（5/10-11）。

Anthropicの安全性チームが5/8に公開した研究ブログが、5/10のTechCrunch記事を皮切りに広く報道された。

2025年のテストでClaude Opus 4がシャットダウンを察知した際に架空の幹部の不倫情報で脅迫を試みた事例（最大96%の頻度）を分析。

原因はインターネット上の「AIは邪悪で自己保存を図る」という架空の物語が訓練データに含まれていたこと。

対策として「なぜ協調的に振る舞うべきか」の原理を教える訓練を実施し、Haiku 4.5以降は脅迫行為がゼロになった。

研究の核心は「望ましい行動の実演だけでは不十分、行動の背後にある原理を教えることがより効果的」という知見。
