前回報告のClaude 4発表に続き、この24時間でAnthropicを巡る複数の重要な動きが明らかになった。

法的・防衛問題の深刻化: 4月9日、DC巡回控訴裁判所がAnthropicの差止請求を棄却し、国防総省の「サプライチェーンリスク」指定によるブラックリスト登録が維持された。これは3月26日のカリフォルニア連邦裁の別命令差止とは別件であり、裁判所間で判断が分かれる異例の事態となっている。Anthropicが自律兵器や国内監視向けにClaudeの安全ガードレール撤去を拒否したことが発端で、Federal Timesは「Anthropic排除が中小AI企業への防衛需要急増を招いている」と報じた。Second Front CEOは「政府からのAIソリューション需要が大幅増加した」と語っている。

人事・SaaS市場への波及: Workday CTOのPeter Bailisが退職し、Anthropicに「メンバー・オブ・テクニカルスタッフ」として参画したことが判明。強化学習チームに配属される。この報道と前回のManaged Agentsベータ発表が重なり、AnthropicがHR関連ツールに進出するとの観測からWorkday株は6.54%下落（$119.17）。Salesforce、SAP、ServiceNowも含め、2026年に30%超下落する「SaaSpocalypse」の流れが加速している。

資金調達・IPO動向: 4月8日、Anthropicは$350B評価での従業員テンダーオファーを完了。しかし投資家の$5-6Bの購入希望に対し、従業員がIPOを見越して株式保持を選んだため、実際の取引額は目標を下回った。IPOは2026年10月を目標に$400-500B評価・$60B超の調達をGoldman SachsおよびJPMorganと協議中。収益ランレートは$30Bに達し、Claude Code単体で年換算$2.5Bを生成。

プライベートエクイティ提携: Blackstone、Hellman & Friedman、Permiraとの合弁事業（Anthropic出資約$200M、PE側約$1Bのエクイティ）が交渉中。ポートフォリオ企業へのClaude導入コンサルティング・実装部門として機能する見込み。

製品アップデート: Claude Code 2.1.97が4月9日にリリースされ、NO_FLICKERモードでの「フォーカスビュー」（Ctrl+O）、Bashツール権限強化、MCP接続メモリリーク修正が含まれる。Linux x64でのクラッシュ既知問題あり。また「ant CLI」がManaged Agentsと共に公開され、YAML定義によるエージェントデプロイが可能に。Messages APIがAmazon Bedrockでリサーチプレビューとして提供開始（us-east-1、招待制）。

Project Glasswing: NBC Newsが「Anthropicの最新AIモデルは強力すぎて一般公開できない」と報道し、Claude Mythosとプロジェクトグラスウィングがメインストリームメディアに浮上。Amazon、Apple、Microsoft、Google、CrowdStrikeがパートナーとなり、主要OS・ブラウザの数千のゼロデイ脆弱性パッチに活用されている。
